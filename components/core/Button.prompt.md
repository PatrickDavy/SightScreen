The push button; labels are sentence-case imperatives ("Record a spell", "See the one thing").

```jsx
<Button icon="video" size="lg" full>Record a spell</Button>
<Button variant="secondary">Not now</Button>
```

Variants: `primary` (ink — the default; never cherry), `secondary` (outlined), `ghost`, `danger` (cherry, destructive/over-limit only). Sizes sm/md/lg; `full` stretches; `icon` takes a Lucide name.
