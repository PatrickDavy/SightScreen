Renders a Lucide icon by name; use for every glyph — never emoji, unicode symbols or hand-drawn SVG.

```jsx
<Icon name="video" size={18} />
<Icon name="shield" size={16} color="var(--turf)" />
```

Requires `<script src="https://unpkg.com/lucide@latest"></script>` on the page. Stroke 2 default; sizes 16/18/20 typical. Icons always sit next to a text label except inside `IconButton`.
