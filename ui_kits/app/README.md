# Sightscreen app UI kit

Interactive recreation of the app's four core surfaces at 390×844: Sessions (home), Record (capture with framing guide), Result (fastest ball + the one thing + measured action), Workload (limits, always free). `index.html` is a working click-through: open a session, record a spell (fake 2.4s measure), toggle km/h·mph, switch age group.

Screens are exported from the bundle (`SessionsScreen`, `RecordScreen`, `ResultScreen`, `WorkloadScreen`) and compose only design-system components. No original product exists — this kit IS the reference design. Guideline figures shown (7 overs a spell, 21 a week) are illustrative placeholders, not quoted ECB directives.
